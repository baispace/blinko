Blinko 编辑器 · Tiptap 接入预览
这是接入后的真实样子（外层样式完全沿用 Blinko，仅编辑内核从 Vditor 换成 Tiptap）
新增能力 现有能力保留

🆕 新增能力（Tiptap 带来）

  • ✦ 斜杠菜单：输入 / 呼出，↑↓ 选择、回车插入块
  • ✦ 块拖拽手柄：悬浮左侧 ⠿ 拖拽整块重排
  • ✦ 气泡菜单：选中文字弹格式浮层
  • ✦ Markdown 快捷输入：# - [] > ``` + 空格
  • ✦ 任务清单、高亮、可视化块结构

✅ 现有能力保留（无缝迁移）

  • ○ 笔记类型切换（闪念/笔记/待办）
  • ○ #标签、引用、资源引用、AI 写作
  • ○ 拖拽上传附件、文件预览
  • ○ 视图模式切换、发送按钮
  • ○ 存量 markdown 内容（通过 markdown 扩展平滑解析）
数据兼容说明：Tiptap 输出标准 HTML（编辑器 getHTML()）。Blinko 现有内容存储为 markdown， 迁移时用 @tiptap/extension-markdown 双向转换即可，旧笔记无需改动、照常渲染。 现有 Vditor 支持的 KaTeX 公式、mermaid、代码高亮等也可通过对应扩展接入（预览页为精简版，未逐一演示）。
