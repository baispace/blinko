## v11 修复：点完成立即同步两份列表内存（用户 01:32 反馈）
- **根因**：`upsertNote.call` 完成后 `updateTicker++` 触发 `refreshData()`，**只 reset `todoList`（isArchived=false），不 reset `doneTodoList`（isArchived=true）**
- **症状**：点完成 → todoList 重 fetch 过滤掉该条 → UI 立即从 todayList 消失；刷新页面 → doneTodoList 重 fetch 包含该条 → `isCompletedToday(updatedAt=now)` 为 true → todayList 合并后重新包含这条
- **修复**：`app/src/components/BlinkoCard/TodoCard.tsx` 的 `toggle` 在调用 `upsertNote.call` 前**同步修改两份 list 的内存数据**：
  - `willArchive=true`：从 todoList 删除 + 加 updated 到 doneList 头部（updatedAt=new Date().toISOString()）
  - `willArchive=false`：从 doneList 删除 + 加 updated 回 todoList 头部
- **结果**：`todayList = todoList ∪ doneList.filter(isCompletedToday)` 立即合并到位，点完即生效，刷新前后行为一致
- **验证**：tsc 干净；Playwright `v11_*.png` 4 个状态全过（点完前 1 张 / 点完后 1 张带删除线 / 刷新后 1 张 / 恢复后 1 张）
