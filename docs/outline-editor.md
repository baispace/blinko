# 大纲与思维导图

在博客/笔记编辑器内使用同一份 Tiptap 文档编辑大纲与思维导图。

## 操作

| 操作 | 效果 |
| --- | --- |
| 行首输入 `- ` | 创建大纲 |
| `/` 菜单搜索「大纲」 | 创建大纲 |
| `Shift + Cmd + \``（Windows/Linux 用 Ctrl） | 创建/退出大纲；普通列表内可转换为大纲 |
| `Cmd + \``（Windows/Linux 用 Ctrl） | 切换当前大纲的列表/思维导图视图 |
| 悬停或编辑当前大纲时出现的右上角图标 | 切换视图 |
| 点击条目左侧圆点 | 折叠/展开子分支 |
| `Enter` | 创建同级条目；选中图片时创建可输入的同级条目 |
| `Tab` / `Shift + Tab` | 缩进 / 提升层级 |
| 空条目按 `Enter`（连续两次回车） | 退出大纲，即使当前在深层分支内 |
| `Cmd + .` | 折叠/展开当前条目的子分支 |
| `Cmd + Z` / `Shift + Cmd + Z` | 撤销 / 重做 |

文字、富文本格式和正文图片都可以保存在条目中。图片使用原有上传入口。
思维导图采用蓝色中心主题、灰色一级卡片、描边子主题和轻量叶子主题，使用弧形连线。
单击主题框选中，按住主题框移动超过 5px 即拖动整条分支；双击、Enter 或 F2 进入文字编辑，Esc 回到选中状态。编辑状态保留文字选择与原有 Enter/Tab 操作；中心主题也可直接改名。默认取大纲前方的标题，没有标题时显示「思维导图」。
无需寻找右上角按钮，从主题框直接拖动即可；编辑文字时仍保留右上角手柄作为备用入口。拖动整条分支：落在另一主题中部成为子项，落在上/下四分之一区域调整同级顺序，落在蓝色中心主题上提升为主分支。
拖动时有虚线预览、蓝色落点与文字提示；无效落点为灰色，不能移入自身或自己的后代。按 Esc 取消，Cmd/Ctrl + Z 撤销。
导图主题右侧的加号/减号用于展开或折叠分支。底部支持 50%～150% 缩放、重置到 100% 和展开画布；展开后可按 Esc 收起。
大型导图可横向/纵向滚动，手机上可滑动，编辑状态下触摸设备显示备用拖动手柄。

大纲沿用正文排版，不显示外框与固定标题。展开时显示普通圆点；收起后圆点带淡圆环。
圆点有悬停、按下反馈，分支高度和留白使用约 190ms 过渡，快速再次点击会反转动画。
开启系统“减少动态效果”时直接切换状态。

已有普通列表不会自动改写：把光标放入列表，使用大纲快捷键转换，保留嵌套关系、正文和图片。
阅读及分享页面支持本地切换视图和折叠分支，这些操作不修改源笔记。
本版拖动修改主题层级与顺序，由树形布局自动安排位置；不包含任意坐标布局或图片导出。

## 保存

应用保存 Markdown，因此大纲以 `<div data-type="outline-block"><ul data-type="outline">…</ul></div>` 存储。
根列表的 `data-view` 保存列表/导图模式，`data-map-title` 保存自定义中心主题，条目的 `data-collapsed` 保存折叠状态。缩放和展开画布是本地显示状态，不写入正文。
序列化图片使用原始 src，避免把渲染时添加的鉴权 token/CDN 地址写进笔记。
普通正文、任务列表和编号列表继续使用已有格式。

## 验证

项目根目录运行：

```sh
node tools/outline-editor-check.mjs
node tools/outline-map-model-check.mjs
```

测试需要开发环境中的 esbuild、Playwright 和已安装的 Chrome；可用 `PLAYWRIGHT_CHANNEL` 指定其他已安装的 Playwright 浏览器通道。
测试使用隔离页面，不登录、不创建或修改任何真实笔记。
可设置 `OUTLINE_SCREENSHOTS=/tmp/blinko-outline-shots` 输出桌面和手机截图。

覆盖输入规则、快捷键、导图内编辑、图片、递归列表转换、深层退出、撤销重做、
Markdown 往返、阅读/分享交互、既有任务列表和深层导图布局。

依赖显式固定 `@tiptap/core` 和 `@tiptap/extension-list-item` 为 v2.27.3。
Vite 的 resolve.dedupe 统一 ProseMirror 实例，避免工作区内重复插件实例导致初始化失败。

新增模型检查覆盖同级排序、改父级、提升为主分支、整棵子树/图片/加粗保留、空子列表清理、循环防护、目标展开和无变化落点。浏览器验证使用独立测试文档，不修改真实笔记。
