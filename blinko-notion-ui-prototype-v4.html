Notion 风格设计语言：行即组件、空白大于边框

这是一篇关于 # 设计 # shadcn 风格的笔记。极简不是简陋，而是克制。Notion 的成功在于把"信息架构"做到了极致。和 @Brian 聊过这个方向。

行即组件

Notion 的列表每一行就是完整的信息单位。它没有厚重的卡片包裹，没有"卡片标题 + 内容 + 操作"的三段式。

关键认知：极简不是简陋，而是克制。设计语言的一致性比"看起来漂亮"更重要。
  • 无边框、靠空白分组
  • 列表项 hover 用极浅灰
  • 选中态：左侧 2px 蓝条 + 浅蓝背景
  • 操作按钮 hover 才浮现
CSS
:root {
  --background: 0 0% 100%;
  --primary: 252 87% 67%;
  --radius: 0.625rem;
}

Notion 风格设计思路
B
帮我分析一下 Notion 风格的核心设计语言，用于设计我们的笔记应用 Blinko。
M

Notion 的设计语言核心是 6 件事：

  1. 行即组件 — 每条记录是行，不是卡片
  2. 空白 > 边框 — 用间距而非线条分隔
  3. hover 显示操作 — 减少视觉噪音
  4. 编辑器即页面 — 进入笔记直接编辑
  5. 命令面板 ⌘K — 万能快捷入口
  6. 细节克制 — 8-12px 圆角、150ms 动画

这些原则很适合笔记应用，因为核心用户的操作频率是"浏览 > 创建 > 编辑 > 分享"。
