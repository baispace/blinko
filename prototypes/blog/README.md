# Ink 博客原型

独立的前端原型源码，供设计预览和后续研发参考，不接入主站导航、路由或发布流程。文章、个人资料和 RSS 为示例数据。

## 本地预览

在本目录执行：

```sh
npm ci
npm run dev
```

默认展示博客页面；在地址后添加 `?review=1` 可切换手机、平板和桌面宽度。

## 构建

```sh
npm run build
npm run preview
```

输出目录为 `dist/client`，构建产物与依赖均不提交。首页、文章详情、专题、作者页、搜索及响应式交互已包含；真实内容发布、管理后台、封面生成与服务端 SEO 仍待正式研发。
