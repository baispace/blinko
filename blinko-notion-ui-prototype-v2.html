Notion 风格设计语言：行即组件、空白大于边框

这是一篇关于 # 设计 # shadcn 风格的笔记。 极简不是简陋，而是克制。Notion 的成功在于把"信息架构"做到了极致。 之前和 @Brian 聊过这个方向，我们看法一致。

行即组件

Notion 的列表每一行就是一个完整的信息单位。它没有厚重的卡片包裹，没有"卡片标题 + 卡片内容 + 卡片操作"的三段式结构。

关键认知：极简不是简陋，而是克制。设计语言的一致性比"看起来漂亮"更重要。

核心 4 条原则

  • 无边框、靠空白分组
  • 列表项 hover 用极浅灰（接近透明）
  • 选中态：左侧 2px 蓝条 + 浅蓝背景
  • 操作按钮 hover 才浮现
CSS 
:root {
  --background: 0 0% 100%;
  --primary: 252 87% 67%;
  --radius: 0.625rem;
}

.notion-row {
  transition: background-color 120ms ease;
}
.notion-row:hover { background: hsl(var(--row-hover)); }
