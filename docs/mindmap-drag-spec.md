## 现在的体验

```
                ┌─────────┐
                │ 目标节点 │  ← 只有这一圈虚线告诉你"会变成它的子"
                └─────────┘
                     ↑
                     │
                ╭────┴────╮
                │ 跟手幽灵 │  ← 一个孤零零的标签，看不出"会接到哪"
                ╰─────────╯
```

- ❌ 抓手在哪？节点文字哪里都能拖，不确定会不会误触
- ❌ 拖到哪？没有"从源到鼠标"的连线，看不见会接在谁下面
- ❌ 兄弟在哪？一条细横线，被节点挤在缝里经常点错档
- ❌ 拖错了？按 ⌘Z 没用，只能肉眼复原
- ❌ 拖完做了什么？动画过渡完就完了，不知道"刚才移到谁下面了"
- ❌ 想复制一份？只能先复制粘贴再拖

## 改进后的体验（核心动效）

### ① 抓手提示 — 节点右上角悬出小六点

```
              拖 ⋮⋮
         ┌─────────┐
         │  节点A  │  ← 鼠标停在文字上：仍走"选中"
         └─────────┘
              拖 ⋮⋮
         ┌─────────┐
         │  节点B  │  ← 鼠标停在右上角小抓手上：进入"拖拽准备"
         └─────────┘
```

- 节点 hover：右上角显出灰色小六点图标 `⋮⋮`
- 抓手上 mousedown：进入拖拽判定
- 文字上 mousedown：仍走"选中"（防误触）
- 移动端：长按 500ms 唤出抓手

### ② 实时连接预览线 — 从源到鼠标画曲线

```
   鼠标到这
        ↓
        ╲
         ╲
          ╲
   ┌───────╲───────┐
   │   目标节点    │  ← 蓝实线 + 末端落点 = 变子级
   └────────────────┘
        ↑
      源节点
        |
        ●═════════════╗
                       ╚═══ 蓝实线 = 会接这里
```

- 拖拽时从**源节点中心**到**鼠标位置**实时画一条贝塞尔曲线
- 蓝实线 + 末端落点是节点盒子 → **变子级**
- 蓝实线 + 末端落点是横线 → **变兄弟**
- 灰虚线 → **无效 drop**（无目标）

### ③ 兄弟插入位置放大版

**现在**：
```
   ┌──────────┐
   │  兄弟 A  │ ───── 3px 细线 ─────
   └──────────┘
```

**之后**：
```
   ┌──────────┐
   │  兄弟 A  │
   └──────────┘
   ━━━━━━━━━━ 8px 横线 ━━━━━━━━━━
   ▴    ⊕ 插入这里    ▾       ← 上下三角 + 末端小气泡
   ┌──────────┐
   │  兄弟 B  │
   └──────────┘
```

- 横线从 3px 涨到 8px
- 两端加上下三角
- 末端一个"⊕ 插入这里"小气泡
- 鼠标越接近横线它微微抖一下（"这里真的能放"反馈）

### ④ 撤销 / 重做 — ⌘Z 救命

```
   误拖了？──→ ⌘Z
               ↓
         ┌──────────────┐
         │ 已撤回：      │
         │ 把「A」移回  │
         │ 「原始位置」  │
         │      ↶ 1.5s 后消失 │
         └──────────────┘
```

- 快捷键：**⌘Z 撤销 / ⌘⇧Z 重做**
- 仅记录**结构性**操作：拖拽改父、新建节点、删除、提降级
- 纯输入文字（打字改文本）不上栈，避免撤销栈被 1000 个字符刷满
- 深度 50（够用就行）

### ⑤ 拖入折叠父 — 落地前先知道"展开是啥样"

**现在**：拖到折叠父身上，只有虚线框，不知道展开后会有几个孩子

**之后**：
```
   ┌──────────────┐
   │ ▾ 折叠父 X   │  ← 普通：实线
   └──────────────┘

   ┌╌╌╌╌╌╌╌╌╌╌╌╌╌╌╌╌╌╌╌╌╌╌╌╌┐  ← 折叠态：虚线 + 12px 迷你预览
   ╎ ▾ X (展开后)          ╎
   ╎   ┄┄┄ A               ╎  ← 3 行 placeholder
   ╎   ┄┄┄ B               ╎
   ╎   ┄┄┄ C               ╎
   └╌╌╌╌╌╌╌╌╌╌╌╌╌╌╌╌╌╌╌╌╌╌╌╌┘
```

- 落到折叠父：虚线指示 + 迷你 placeholder（3 行模拟子节点）
- drop 时自动展开，再写入大纲

### ⑥ 拖完 toast 反馈

```
   ┌──────────────────────────────────────┐
   │ ✓ 已把「用户」移到「策略评估」下  ↶  │  ← 1.5s 自动消失
   └──────────────────────────────────────┘
```

- drop 后右下角浮一条 1.5s toast
- 描述本次操作（"把 X 移到 Y 下"）
- 配 ↶ 按钮一键撤销

### ⑦ Alt 复制 + 多选

```
   按住 ⌘ 选中多个 ───→ 一起拖走（整组结构保持）
                    ┌──────┐
                    │ A    │─┐
                    └──────┘ ├─ 一起搬
                    ┌──────┐ │
                    │ A's  │─┘
                    └──────┘

   按住 Alt 拖 ───→ 复制而非移动（落点会显示"⊕ 副本"标记）
```

- **Alt/Option + 拖** = 复制（markmap 模式）
- **⌘/Ctrl + 点击** = 多选，拖其中一个整组搬
- 内置引擎是否也支持复制（待你定，见末尾问题 3）
