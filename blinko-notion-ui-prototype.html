Notion 风格设计语言：行即组件、空白大于边框

这是一篇关于 # 设计 # shadcn 风格的笔记。 极简不是简陋，而是克制。Notion 的成功在于把"信息架构"做到了极致。

行即组件

Notion 的列表每一行就是一个完整的信息单位。它没有厚重的卡片包裹，没有"卡片标题 + 卡片内容 + 卡片操作"的三段式结构。

每条 note 就是一行。点击进入详情，回到列表自动滚回原位。

关键认知：极简不是简陋，而是克制。设计语言的一致性比"看起来漂亮"更重要。

空白大于边框

分隔靠 24-32px 空白，而不是 1px 边框。 选中态靠 左侧 2px 高亮条，而不是整块蓝。 阴影尽量避免，最多 0 1px 2px rgba(0,0,0,.04)。

  • 无边框、靠空白分组
  • 列表项 hover 用极浅灰（接近透明）
  • 选中态：左侧 2px 蓝条 + 浅蓝背景
  • 操作按钮 hover 才浮现

shadcn/ui 的角色

shadcn/ui 提供底层组件（Button / Dialog / DropdownMenu 等）和设计 token 系统。 真正的 Notion 化由你的 layout / spacing / typography 决定，不是组件本身。 

:root {
  --background: 0 0% 100%;
  --primary: 252 87% 67%;
  --radius: 0.625rem;
}

.notion-row {
  transition: background-color 120ms ease;
}
.notion-row:hover { background: hsl(var(--row-hover)); }

💡 设计应该像水一样，无形却能装进任何容器。
