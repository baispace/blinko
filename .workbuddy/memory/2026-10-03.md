## 修复「发布到主页」弹窗发布按钮不可见
- 现象：弹窗只剩「关闭」按钮，用户点不了发布
- 根因：`BlinkoPublishDialog` 发布按钮用了 `bg-[var(--heo-main)]`，但该变量在本代码库不存在 → background 计算为 transparent + `text-white` → 白底白字隐形（按钮在 DOM 里、占位正常，就是看不见）
- 修复：改为全 App 规范的 `bg-primary text-primary-foreground`（取消发布态 `bg-danger text-white`）
- Playwright 验证：按钮可见（rgb(0,0,0) 底）、点击发布 → 已发布+取消发布出现、取消还原、零 pageerror
- 顺带更正 MEMORY.md 里过时的 `--heo-main` 主色记录
- 已于 2026-10-03 提交：37e2cf22(feat 发布到主页) / dcc0e26e(fix heo 命名与失效变量) / 4fea0273(docs 记忆)；**未推送、未触发 CI**，等用户指令

## heo 残留清理 + CSS 变量全量扫描
- `heo` 来源：UI 借鉴 HEO 博客主题留下的命名。**源码里 `--heo-main` 从未存在过**（`git log -S heo-main` 无记录），是我此前记忆笔记写错
- 真正残留只有 `heo-shadow-card` 类 ×2（CSS 里无定义 = 死类名，阴影不生效）→ 改为 `shadow-sm`(PerferSetting) / `shadow-md`(Editor 全屏按钮，与全屏态对称)
- 另改 2 处 HEO 注释为中性表述。现 `grep -i heo src` 只剩 "theory" 单词
- 顺手全量扫描「源码引用但本地 CSS 未定义」的变量（脚本 /tmp/varscan.mjs）：8 个疑似里 `--app-font-size/--app-font-weight/--doc-height/--min-editor-height/--blinko-card-spacing` 是 JS setProperty 注入且有 fallback、`--heroui-colors-*` 由 HeroUI 插件提供，均正常
- 唯一真 bug：`github-markdown.css` 用 `var(--base-size-2)`，但 base-size 系列只有 4/8/16/24/40 → 声明整条失效。已改 `var(--base-size-2, 0)` 保持零视觉变化（p 实际 8px 来自别的规则、pre 0px 与改动前一致）；若想恢复"预期间距"应改成 `--base-size-16`，但会全局改 markdown 间距，需用户拍板
- 排查手法：CDP `CSS.getMatchedStylesForNode` 看 margin 命中链（发现 `.markdown-body pre{margin-bottom:0}` + `> :last-child{margin-bottom:0!important}` 会盖住改动）
