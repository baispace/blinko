## 链接预览 favicon 外链超时（控制台 ERR_TIMED_OUT）
- 现象：笔记里 GitHub 链接 → LinkPreview 卡片 `<Image src=github.githubassets.com/favicons/favicon.svg>` → 浏览器 ERR_TIMED_OUT
- **关键认知：服务端可达 ≠ 浏览器可达**（服务端 curl 该 URL 200/0.38s，用户浏览器却超时，可能因服务端走代理）。所以"后端探测可达性再决定返回"（方案 A）**无效**，实测 github favicon 仍被判定可达
- 最终方案：后端 `public.ts` 把 favicon 下载成 **data URI**（≤64KB、只放行 image/svg/octet-stream、5s 超时、走 getWithProxy 兼容代理），前端 src 变 `data:image/...` → 浏览器零外部请求。无需新增对外接口，无 SSRF 面扩大
- 前端 `LinkPreview` 加 `onError` 自愈：失败把缓存里的 favicon 置空（previewData 是 StorageState 持久化，旧缓存仍可能是 http 外链）
- 验证：接口返回 data:image/svg+xml;base64（1.3KB）；Playwright 页面 img src 全为 data URI、非同源请求 0、console 无错；tsc 55 基线零新增

## 列表/详情换行与 callout 渲染修复（问题1、问题2）
- **问题1 换行"保存后再打开就没了"——根因最终定位（2026-10-03 下午，推翻上午误判）**：
  - 上午误判：以为根因是 hardBreak 反斜杠 + 渲染没消费。错。反斜杠续行 `A\\\nB`（Shift+Enter 产生）在 `breaks:false` 下**能正常往返**，不是元凶。
  - **真根因（真实 tiptap + jsdom 往返实测坐实）**：`useEditor.ts` 的 `Markdown.configure({breaks:false})` 下，markdown 的**单个裸换行** `A\nB`（源码/MD 视图里回车、粘贴、AI 生成内容最常见的形态）在 `getMarkdown()` 序列化时被**直接压成空格**（`"A B"`），再打开即"换行没了"。段落（双换行 `A\n\nB`）和反斜杠硬换行都不受影响 → 所以只盯"回车=段落"会误判。
  - **真正修复 = `breaks:true`**（`useEditor.ts`）：单换行稳定保真为硬换行，且对段落/反斜杠形态向后兼容（实测序列化结果不变）。
  - 之前加的 `stripTrailingBackslashes`/`remarkBreaks` 属**阅读态**补丁（处理 `A\\\nB`→br），对编辑器**保存/重开**的序列化无效，故单独无效。两者互补：编辑侧改 `breaks:true` 后硬换行存成 `A\\\nB`，渲染侧去反斜杠+remarkBreaks 协同显示。
- **问题2 callout 在列表显示 HTML 符号**：缩进的 callout（粘贴/AI 生成带行首空格）会被 markdown 当成**缩进代码块** → 原样显示 `<div data-callout...>`。修复 `liftIndentedCallouts()` 把 callout 块行首缩进抬到顶层。验证：缩进 callout 渲染 `showsHtmlSymbol:false` 且正确成 `[data-type=callout]` 元素
- **关键确认**：列表卡片 `NoteContent`(BlinkoCard/noteContent.tsx:106) 也走 `MarkdownRender`，所以两修复对列表+详情同时生效

## dev server 反复 502 / 用户"重启后仍不行"的真因 + 稳定性收口
- **现象**：改完 `breaks:true` 后用户反馈"重启后换行还是没生效"。实测服务 `/health` 返回 502、端口 1111 无监听 —— 服务根本没在跑。
- **根因**：之前用 `nohup bun run dev > log 2>&1 &` 在 Bash 工具里后台拉起，命令结束、工具向进程组发 SIGHUP → bun 日志里 `terminated by signal SIGHUP (Terminal hung up)` 进程被杀。所以"重启"没真正保活，用户测的是 502。
- **正确起法（已验证）**：用 Bash 工具 `run_in_background:true` 跑**前台** `bun run dev`（exec 直接当托管任务子进程），由任务管理器持有，不受回合结束 SIGHUP 影响。OrbStack 退出时先 `open -a OrbStack` 再 `docker start blinko-dev-pg`。
- **docker 坑**：非交互 zsh 的 PATH 不含 docker；用 `bash -lc 'docker ...'` 或全路径 `/usr/local/bin/docker`（软链到 OrbStack）。
- **最终端到端验证（真实 Chrome + 注入 token）全绿**：
  - 显示侧（`/detail` MarkdownRender + remarkBreaks）：单换行内容 `line1\nline2\nline3` 渲染为 3 行 ✓
  - 编辑侧（Tiptap `breaks:true` 解析）：右键卡片→编辑弹窗，`.tiptap` 读 `line1\nline2\nline3` 三行；带行内格式 `**bold**\nnormal\n\`code\`` 也是三行 ✓；段落 `A\n\nB` 五行(含空行) ✓
  - **保存往返**：编辑态末尾追加标记并自动保存 → DB 内容换行完整保留（`SAVE PRESERVED LINE BREAKS: true`，标记已落库）→ 重开不会再丢换行
- 结论：`breaks:false` 唯一会丢的是**单换行/软换行**形态（粘贴/AI 生成最常见）；`breaks:true` + 阅读侧 remarkBreaks/stripTrailingBackslashes/liftIndentedCallouts 互补，已彻底修复。用完清理测试笔记 118-125、临时脚本 /tmp/e2e_*.mjs 等。
